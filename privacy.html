سیاست حفظ حریم خصوصی برق‌یار

این صفحه توضیح می‌دهد هنگام استفاده از برنامه برق‌یار چه اطلاعاتی دریافت می‌شود و چگونه مورد استفاده قرار می‌گیرد.

۱. اطلاعات دریافتی هنگام ثبت سفارش

در صورت ثبت سفارش، اطلاعاتی از جمله نام و نام خانوادگی، شماره تلفن همراه، نشانی تحویل، اقلام سفارش، تعداد، قیمت ثبت‌شده و کد پیگیری دریافت یا پردازش می‌شود.

۲. محل نگهداری اطلاعات

اطلاعات کالاها و سفارش‌ها در پایگاه داده ابری پروژه برق‌یار با استفاده از سرویس Supabase نگهداری می‌شود. فایل‌های برنامه و صفحات مرتبط از طریق GitHub Pages میزبانی می‌شوند.

۳. نحوه استفاده از اطلاعات

اطلاعات برای ثبت و بررسی سفارش، بررسی کالاها و قیمت‌ها، تماس و هماهنگی با مشتری، هماهنگی ارسال و تحویل، ثبت وضعیت سفارش و پاسخ‌گویی به درخواست‌ها و مشکلات کاربران استفاده می‌شود.

۴. ارسال اطلاعات سفارش

کاربر می‌تواند سفارش خود را از طریق روش‌های ارائه‌شده در برنامه از جمله واتساپ، تلگرام یا ایمیل ارسال کند. در صورت انتخاب این روش‌ها، اطلاعات لازم برای ثبت و هماهنگی سفارش در اختیار سرویس انتخاب‌شده و گیرنده مربوط قرار می‌گیرد. ارسال ایمیل سفارش ممکن است از طریق سرویس FormSubmit انجام شود.

۵. پیگیری سفارش

کدهای پیگیری سفارش ممکن است برای استفاده از قابلیت پیگیری در حافظه محلی مرورگر ذخیره شوند. این فهرست محلی به‌طور خودکار به مرورگر یا دستگاه دیگری منتقل نمی‌شود. حذف اطلاعات مرورگر یا استفاده از دستگاه دیگر ممکن است دسترسی به فهرست محلی کدهای پیگیری را محدود کند.

۶. ثبت بازخورد و امتیاز

ارسال نظر، امتیاز یا گزارش مشکل اختیاری است. فرم بازخورد اطلاعاتی مانند امتیاز، موضوع و شرح کوتاه را دریافت می‌کند. برای محدود کردن ارسال‌های تکراری، ممکن است شناسه فنی هش‌شده‌ای از نشانی شبکه استفاده شود؛ نشانی خام شبکه در جدول بازخورد مورد اشاره ذخیره نمی‌شود. بازخوردها برای بررسی مشکلات و بهبود برنامه استفاده می‌شوند و دسترسی مدیریتی به آن‌ها محدود است.

۷. سرویس‌های ثالث

برق‌یار از خدمات زیرساختی و سرویس‌های ثالث از جمله Supabase برای پایگاه داده و خدمات مرتبط، GitHub Pages برای میزبانی فایل‌ها و صفحات، FormSubmit برای ارسال فرم‌ها و ایمیل‌های مرتبط و واتساپ و تلگرام در صورت انتخاب کاربر استفاده می‌کند. هر سرویس ثالث تابع شرایط و سیاست‌های خود است.

۸. دسترسی به اطلاعات

اطلاعات سفارش و بازخورد برای مدیریت و رسیدگی به سفارش‌ها و درخواست‌های کاربران در اختیار مدیر برنامه قرار می‌گیرد. اطلاعات کاربران برای اهداف مرتبط با ارائه خدمات برق‌یار استفاده می‌شود.

۹. امنیت اطلاعات

برق‌یار تلاش می‌کند با استفاده از زیرساخت‌های فنی و اقدامات متعارف از اطلاعات کاربران حفاظت کند. با این حال، هیچ روش انتقال یا ذخیره‌سازی اینترنتی را نمی‌توان کاملاً عاری از خطر امنیتی دانست.
